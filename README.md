# excel-vba-round-selected-cells

一个简单实用的 Excel VBA 宏，用于对选中区域中的数字进行四舍五入，保留两位小数。  
支持普通数值、百分比格式、文本混合内容，并自动将纯数字文本转换为数字格式。

## ✨ 功能特性

- ✅ 对选中单元格中的数值四舍五入，保留两位小数
- ✅ 百分比格式：直接处理百分号前的数字，例如 `12.345%` → `12.35%`
- ✅ 文本混合内容：仅处理第一个数字，后面的文字、符号、百分号等保持不变  
  例如：`12.345abc` → `12.35abc`；`12.345%` → `12.35%`
- ✅ 纯数字文本自动转为数字格式（例如 `"12.345"` → 数字 `12.35`）
- ✅ 跳过公式单元格、日期单元格和空单元格
- ✅ 支持千分位逗号，例如 `1,234.567` → `1,234.57`

## 📥 使用方法一：直接导入 VBA 模块

1. 下载本仓库中的 `RoundSelectedTo2Decimals.bas` 文件。
2. 打开 Excel，按 `Alt + F11` 打开 VBA 编辑器。
3. 在菜单栏选择 **文件** → **导入文件**，选择下载的 `.bas` 文件。
4. 关闭 VBA 编辑器，返回 Excel。
5. 选中需要处理的单元格区域（可多选）。
6. 按 `Alt + F8`，选择 `RoundSelectedTo2Decimals`，点击 **运行**。

## 📦 使用方法二：作为 Excel 加载宏使用（推荐）

如果你希望每次打开 Excel 都能直接使用该宏，而无需重复导入模块，可以将它制作成加载宏（`.xlam`）。

### 创建加载宏

1. 新建一个空白 Excel 工作簿。
2. 按 `Alt + F11` 打开 VBA 编辑器。
3. 在菜单栏选择 **文件** → **导入文件**，导入 `RoundSelectedTo2Decimals.bas`。
4. 关闭 VBA 编辑器。
5. 在 Excel 中点击 **文件** → **另存为**。
6. 将保存类型选择为 **Excel 加载宏 (*.xlam)**，文件名例如 `RoundSelectedTo2Decimals.xlam`，保存到任意位置（建议默认的加载宏文件夹）。

### 加载使用

1. 打开 Excel，点击 **文件** → **选项**。
2. 在左侧选择 **加载项**。
3. 在底部“管理”下拉框中选择 **Excel 加载项**，点击 **转到**。
4. 点击 **浏览**，找到并选择刚才保存的 `.xlam` 文件，点击 **确定**。
5. 加载成功后，选中需要处理的单元格区域，按 `Alt + F8`，选择 `RoundSelectedTo2Decimals` 并运行即可。

## 🔘 在快速访问工具栏添加按钮（配合加载宏）

将宏添加到快速访问工具栏后，只需选中单元格区域，点击一下按钮即可运行，非常方便。

1. 确保已经按照 **使用方法二** 加载了该宏。
2. 点击 Excel 窗口左上角快速访问工具栏右侧的 **下拉箭头**（或右键点击工具栏），选择 **其他命令**。
3. 在 “Excel 选项” 对话框中，将 **从下列位置选择命令** 下拉框改为 **宏**。
4. 在列表中找到 `RoundSelectedTo2Decimals`，选中后点击 **添加**，将其加入右侧列表。
5. （可选）选中右侧的宏名称，点击 **修改**，可以更换按钮图标和显示名称，例如改为“四舍五入”。
6. 点击 **确定** 关闭对话框。
7. 现在快速访问工具栏上会出现一个按钮，选中需要处理的单元格区域后，点击该按钮即可运行宏。

> 💡 此方法同样适用于使用方法一导入的宏，但加载宏方式可以保证按钮在所有工作簿中始终可用。

## ⚙️ 注意事项

- 默认**跳过公式单元格**，若需处理公式单元格，请删除代码中对应的判断行。
- 默认**跳过日期单元格**，避免日期被误转换。
- 代码假定单元格中的数字格式为常规或文本，对于复杂混合格式仅处理第一个出现的数字。
- 如果单元格内容为错误值（如 `#DIV/0!`），会被忽略。
